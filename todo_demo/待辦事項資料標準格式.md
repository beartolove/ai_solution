

| 欄位名稱     | 說明       | 資料規範                             |
| -------- | -------- | -------------------------------- |
| 任務編號     | 任務唯一識別碼  | 文字，不可重複、不可空白，例如 T001             |
| 任務名稱     | 工作事項名稱   | 文字，不可空白                          |
| 工作類別     | 任務所屬業務類別 | 系統維運、硬體設備、軟體管理、資安管理、行政作業、專案管理、其他 |
| 優先順序     | 任務重要程度   | 高、中、低                            |
| 工作狀態     | 任務目前執行狀態 | 未開始、進行中、已完成                      |
| 建立日期     | 任務建立日期   | YYYY-MM-DD，不可空白                  |
| 預計完成日期   | 原訂完成期限   | YYYY-MM-DD，原則上不可空白               |
| 實際完成日期時間 | 任務實際完成日期 | YYYY-MM-DD HH:mm:ss，未完成時留空       |
| 開工日期時間   | 任務實際開始作業時間 | YYYY-MM-DD HH:mm:ss，未開工時留空                  |
| 完工日期時間   | 任務實際完工作業時間 | YYYY-MM-DD HH:mm:ss，未完成時留空                  |
