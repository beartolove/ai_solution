# 待辦事項管理

一個免安裝、可離線使用的繁體中文待辦事項網頁工具。只要用瀏覽器開啟 `index.html`，即可開始使用。

目前版本：**1.5.8**

## 開始使用

1. 以瀏覽器開啟 `index.html`。
2. 在「新增待辦」填寫任務名稱、工作類別、預計完成日期與優先順序。
3. 按下「新增」後，資料會自動儲存在此瀏覽器中。

## 功能

- 上方工具列將主標題、版本與「新增待辦」按鈕集中在同一列；按下按鈕後以燈箱表單新增事項。
- 新增、編輯與刪除待辦事項；待辦清單的「編輯」按鈕與今日聚焦卡片都會開啟可儲存的燈箱表單。
- 以核取方塊或工作狀態選單標示「未開始／進行中／已完成」；首次切換為進行中時記錄開工日期時間，切換為已完成時記錄完工日期時間與實際工時（天／小時）。
- 依未完成、已完成或全部查看事項。
- 依優先順序、截止日或建立日期排序，並可搜尋事項名稱與分類。
- 設定 3、4 或 5 件「今日聚焦」事項；可一鍵依優先順序挑選。
- 從待辦清單拖曳未完成事項到今日聚焦，或在聚焦區拖曳重新排序。
- 漢堡選單中的「資料管理」可依資料標準格式匯出目前所有待辦為 UTF-8 CSV，或匯入同格式 CSV。
- 漢堡選單提供「清空紀錄」，清除前會再次確認；此操作會移除目前瀏覽器中的所有待辦與今日聚焦資料，且無法復原。
- 左上角漢堡選單可切換 Light／Dark 主題與字體大小；偏好設定會保留在目前瀏覽器。
- 編輯模式將「今日聚焦」與「待辦清單」以雙欄並列，減少捲動；小螢幕會自動改為單欄。
- 可在「編輯模式」與「聚焦模式」之間切換；聚焦模式會隱藏其他工作區，只保留今日聚焦事項與切換選單。
- 新增與編輯燈箱會隨視窗高度捲動、隨可用寬度自動換行欄位，避免日期與下拉選單在大字體或小螢幕時被遮住。
- 深色模式下，新增與編輯燈箱固定使用白色底與深色文字，與背景清楚區隔。
- 網頁介面的日期一律顯示為 `YYYY/MM/DD`，日期時間一律顯示為 `YYYY/MM/DD HH:mm:ss`；CSV 仍依範例規格使用連字號格式。
- 「進行中」狀態的下拉選單與清單中的狀態文字會使用顯眼色塊及粗體標示；未開始與已完成維持一般文字。
- 未開始的事項只顯示基本資料、預計完成日期與狀態；開工、完工與實際工時會在進行中或已完成後顯示。

## 資料與隱私

所有待辦資料都儲存在瀏覽器的本機儲存空間，不會上傳到網路。清除瀏覽器的網站資料、使用無痕模式，或改用不同瀏覽器／裝置，都可能看不到原本的資料；建議定期使用「匯出 CSV」備份。

## 匯入 CSV 格式

匯入與匯出均參考 `待辦事項範例.csv`；匯出的 CSV 可直接再次匯入。匯入時必須使用下列欄位名稱與順序：

```csv
任務編號,任務名稱,工作類別,優先順序,工作狀態,建立日期,預計完成日期,實際完成日期時間,開工日期時間,完工日期時間
T001,準備簡報,專案管理,高,進行中,2026-10-18,2026-10-20,,2026-10-18 09:00:00,
```

系統會自動產生且隱藏「任務編號」；自行匯入時須提供不重複的任務編號。工作類別限於「系統維運、硬體設備、軟體管理、資安管理、行政作業、專案管理、其他」。建立日期與預計完成日期為 `YYYY-MM-DD`；日期時間為 `YYYY-MM-DD HH:mm:ss`。

## 專案檔案

- `index.html`：正式應用程式入口，包含畫面、樣式與互動程式。
- `README.md`：使用方式與資料格式說明。
- `CHANGELOG.md`：版本變更紀錄。
- `todo_v1.html` 至 `todo_v3.html`：保留的開發版本。
