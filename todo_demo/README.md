# 待辦事項管理

一個免安裝、可離線使用的繁體中文待辦事項網頁工具。只要用瀏覽器開啟 `index.html`，即可開始使用。

目前版本：**1.7.5**

## 開始使用

1. 以瀏覽器開啟 `index.html`。
2. 在「新增待辦」填寫任務名稱、工作類別、預計完成日期與優先順序。
3. 按下「新增」後，資料會自動儲存在此瀏覽器中。

## 功能

- 上方工具列將主標題、版本與「新增待辦」按鈕集中在同一列；按下按鈕後以燈箱表單新增事項。
- 新增與編輯待辦事項；按下待辦清單任一事項或今日聚焦卡片，都會開啟可儲存的燈箱表單。
- 以工作狀態選單標示「未開始／進行中／已完成」；首次切換為進行中時記錄開工日期時間，切換為已完成時記錄完工日期時間與實際工時（天／小時）。
- 依未完成、已完成或全部查看事項。
- 依優先順序、截止日或建立日期排序，並可搜尋事項名稱與分類。
- 設定 3、4 或 5 件「今日聚焦」事項；從待辦清單拖曳未完成事項到今日聚焦，並可在聚焦區拖曳重新排序。
- 今日聚焦卡片可直接按「★ 完成」獲得當日星星；完成當日所有聚焦事項時會施放煙火，之後可按星星區再次播放。
- 新增與編輯待辦時可填寫「應注意事項」；滑鼠移至待辦或今日聚焦卡片時會顯示提醒內容。
- 漢堡選單中的「資料管理」可依資料標準格式匯出目前所有待辦為 UTF-8 CSV，或匯入同格式 CSV。
- 漢堡選單提供「清空紀錄」，清除前會再次確認；此操作會移除目前瀏覽器中的所有待辦與今日聚焦資料，且無法復原。
- 漢堡選單的「操作說明」會以燈箱顯示新增待辦、更新狀態、今日聚焦、顯示設定與 CSV 備份方式。
- 左上角漢堡選單可切換 Light／Dark 主題與字體大小；偏好設定會保留在目前瀏覽器。
- 編輯模式將「今日聚焦」與「待辦清單」以雙欄並列，減少捲動；小螢幕會自動改為單欄。
- 桌面版會固定頂端功能與今日聚焦區，只讓待辦清單內部捲動；小螢幕維持一般頁面捲動。
- 可在「編輯模式」與「聚焦模式」之間切換；聚焦模式會隱藏其他工作區，只保留今日聚焦事項與切換選單。
- 新增與編輯燈箱會隨視窗高度捲動、隨可用寬度自動換行欄位，避免日期與下拉選單在大字體或小螢幕時被遮住。
- 新增與編輯燈箱固定置中顯示；每個欄位採左側標籤、右側欄位的單列排列，預計完成日期可使用日曆元件選取，關閉按鈕採用圓形圖示設計。
- 新增與編輯燈箱中可匯出至 CSV 的欄位會以淺黃色底色標示。
- 畫面上的輸入、搜尋與下拉選單等表單欄位統一使用淺黃色底色，方便辨識可操作區域。
- 深色模式下，新增與編輯燈箱固定使用白色底與深色文字，與背景清楚區隔。
- 網頁介面的日期一律顯示為 `YYYY/MM/DD`，日期時間一律顯示為 `YYYY/MM/DD HH:mm:ss`；CSV 仍依範例規格使用連字號格式。
- 待辦清單以彩色 hashtag 呈現工作類別、優先順序與工作狀態；可快速辨識資訊且不重複顯示核取方塊。
- 未開始的事項只顯示基本資料、預計完成日期與狀態；開工、完工與實際工時會在進行中或已完成後顯示。
- 進行中的事項只顯示開工日期時間；完工日期時間與實際工時只會在完成後顯示。
- 待辦清單項目採用清晰卡片邊框；滑鼠移到項目時，該筆會突出顯示，其餘項目會暫時淡化。

## 資料與隱私

所有待辦資料都儲存在瀏覽器的本機儲存空間，不會上傳到網路。清除瀏覽器的網站資料、使用無痕模式，或改用不同瀏覽器／裝置，都可能看不到原本的資料；建議定期使用「匯出 CSV」備份。

## 匯入 CSV 格式

匯入與匯出均參考 `待辦事項範例.csv`；匯出的 CSV 可直接再次匯入。匯入時必須使用下列欄位名稱與順序：

```csv
任務編號,任務名稱,工作類別,優先順序,工作狀態,建立日期,預計完成日期,實際完成日期時間,開工日期時間,完工日期時間,應注意事項
T001,準備簡報,專案管理,高,進行中,2026-10-18,2026-10-20,,2026-10-18 09:00:00,,先確認簡報設備
```

系統會自動產生且隱藏「任務編號」；自行匯入時須提供不重複的任務編號。工作類別限於「系統維運、硬體設備、軟體管理、資安管理、行政作業、專案管理、其他」。建立日期與預計完成日期為 `YYYY-MM-DD`；日期時間為 `YYYY-MM-DD HH:mm:ss`。「應注意事項」可留空；如內容有逗號、換行或雙引號，請遵循 CSV 的雙引號跳脫規則。

## 專案檔案

- `index.html`：正式應用程式入口，包含畫面、樣式與互動程式。
- `README.md`：使用方式與資料格式說明。
- `CHANGELOG.md`：版本變更紀錄。
- `todo_v1.html` 至 `todo_v3.html`：保留的開發版本。
