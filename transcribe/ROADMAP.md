# 開發路線圖（ROADMAP）

> 目標流程：**任何影音來源 → SRT 逐字稿**（辨識直接讀原始檔，需要時才另存 MP3），依三個層次逐步提升：
> (A) 能轉出逐字稿 → (B) 專有名詞正確率 ≥ 95% → (C) 標出不同說話者
>
> 原則：先做出能用的命令列核心，再接網頁介面；每完成一個階段就遞增版號並更新 README／CHANGELOG。

    - 只寫 `cookies.txt` 一個檔名、不刪任何檔案；網域清單可勾選（YouTube／Google、FB、IG、Threads、X、Bilibili…）。

- **下載策略**：先不帶 cookies 下載 → 遇到需要登入、會員限定、被擋（403／bot 驗證）才自動改用 `cookies.txt` 重試 → 仍失敗才白話提示（例如「請在 Chrome 按擴充功能的同步」）。
- **本專案要做的**：web.py 加 `/api/ping`、`/api/cookies`（轉存 `data\cookies.txt`，Netscape 格式，`data\` 不進版控、不顯示內容）、`/api/enqueue`（加入轉逐字稿佇列）。

**引擎決策（0.3.1 調整）**
- 原規劃等級 C/D 用 whisper.cpp，但官方 Windows 版只有 CPU 版，無法用 Intel 顯示卡加速。
- 改用 **Intel OpenVINO**（openvino-genai `WhisperPipeline`）：Intel 顯示卡可加速、任何 CPU 也能跑，支援 `initial_prompt`／`hotwords`（層次 B 會用到），且 mov_downloader 已實際使用。
- 0.2.x 下載的 GGML 模型（`D:\models\asr\ggml\`，約 2.4GB）已不使用，引擎驗證後可刪除。

**Hugging Face 政策（使用者不需要帳號）**
- Breeze、Whisper 等公開模型匿名下載即可。
- 需同意條款的模型（pyannote）由管理者一次性下載；OpenVINO 模型由管理者轉換一次；其他電腦從共用來源（環境變數 `MODELS_SOURCE`）複製。

**檢查點：引擎實測**
