# 專有名詞庫（glossary）

每個主題一個 CSV 檔（UTF-8，可直接用 Excel 開啟編輯），處理時可選擇套用哪些詞庫。

## 欄位說明

| 欄位 | 說明 |
|---|---|
| 正確寫法 | 逐字稿最終要出現的寫法 |
| 常見誤寫 | 模型可能聽錯的寫法，多個用 `\|` 分隔；會在辨識後自動替換成正確寫法 |
| 只提醒 | 「常見誤寫」中本身也是常用詞的（例：船隻、飲水、船首），只列出提醒、不自動替換；多個用 `\|` 分隔（0.11.0） |
| 分類 | 港務專業術語／港口與地名／船舶名稱／系統及設備／業務專用詞 |
| 英文／全稱 | 英文名稱或縮寫全稱，供查詢與 LLM 校正參考 |
| 說明 | 補充說明 |
| 提示優先 | 1＝一定放進 Initial Prompt；2＝詞數允許時才放；3＝只用於事後替換 |

## 使用原則
- Whisper 的 Initial Prompt 上限約 224 個 token，所以只放「提示優先＝1」且最容易聽錯的詞。
- 「常見誤寫」目前是依讀音**預先推測**，實際以測試音檔辨識結果為準：轉完後把真正出現的錯字補進來，正確率會一次比一次好。
- 英文縮寫（AIS、VTS、TEU…）一律以大寫、不加空格為正確寫法。
- 「臺／台」：正確寫法依官方名稱用「臺」，辨識出的「台」會自動替換。
