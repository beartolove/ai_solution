設定 API Key

只需完成一次。先選來源、填入臨時金鑰，再進行教學與測試。

Azure 已公開的 Responses API 不等同 Decisions API。此處允許輸入自訂 Decisions 端點以便驗證；若回傳 404 或不支援，請改用 OpenAI 官方 API。

按下「儲存／覆蓋金鑰」才會將目前的 API Key 存入此瀏覽器 localStorage（明文儲存，同網站其他程式可能讀取）；共用電腦或公開環境不建議使用。瀏覽器直接呼叫仍可能遇到 CORS 或金鑰暴露風險；請使用限額、可撤銷的臨時金鑰。sk 開頭不足以判斷服務商，務必對應正確的 API 來源。
