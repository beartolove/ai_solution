    重點摘要

    本機 Gemma 4 的大小與執行裝置在下方「本機 AI 模型」設定。長影片在本機摘要可能要數分鐘到十幾分鐘，品質通常不如雲端 AI，適合沒有網路或不想上傳時使用。

    本機 Codex 設定（翻譯與重點摘要共用）：需先在電腦上安裝 Codex CLI（npm install -g @openai/codex），並在命令提示字元執行 codex login 登入。摘要時會以唯讀模式呼叫 codex exec，每次呼叫約需數秒到數十秒。

    找執行檔、檢查版本、實際呼叫一次
      語音辨識（影片沒有字幕時）

      流程：用 ffmpeg 把 MP4 抽出聲音成 MP3，再用語音辨識模型辨識成 SRT，之後依上方字幕設定轉成台灣用語或翻譯。全程在你的電腦上執行，不會上傳聲音。

      「自動」依影片的原始語言判斷（舊影片沒有記錄時看標題與簡介）；判斷不出來時用 Breeze。下方「影片語言」選了英文、日文、韓文時也會改用 turbo。

      本機 AI 模型

      語音辨識、本機翻譯、本機重點摘要用的模型都放在同一個「模型位置」，每個模型在底下有固定的資料夾，和「影音轉逐字稿」（transcribe）專案共用同一份，不用重複下載。本程式不會刪除模型。

      隱藏影片

      加上 #隱藏 的影片預設不會出現在影片庫與下載佇列，要在影片庫按「隱藏影片」並輸入密碼才看得到。

      注意：這是介面上的隱藏，影片檔仍在下載資料夾中，用檔案總管還是看得到。

      快速上手

      1. 在「下載佇列」貼上一個或多個影片網址，按 加入佇列，程式會依序下載。
      2. 影片存成 MP4，檔名使用影片原標題；字幕存成同名的 .zh-TW.srt／.en.srt。
      3. 到「影片庫」點選影片即可播放，可切換字幕、調整速度與全螢幕。

      需要登入的影片

      請先安裝專案內 chrome_extension 資料夾的 Chrome 擴充功能（開發人員模式 →「載入未封裝項目」），在 Chrome 登入各網站後，按擴充功能的 同步 Cookie。擴充功能也會每 30 分鐘自動同步一次。

      會員影片 Chrome 能播、下載器卻說沒有會員資格？這通常是 YouTube 把一般分頁的登入 Cookie 輪替掉了。請改用無痕視窗同步：① chrome://extensions →「影片下載器同步」→「詳細資料」開啟「允許在無痕模式下執行」；② 開無痕視窗（Ctrl+Shift+N）登入有會員的 YouTube 帳號；③ 點擴充功能 →「從無痕視窗同步 YouTube 登入」；④ 直接關閉無痕視窗（不要登出）。

      重點摘要

      播放器按 📝 重點摘要，AI 會依原始字幕整理成最多 5 頁的簡報：第 1 頁是影片主旨、hashtag、100 字內大綱，以及是否「講概念／有範例／有程式」，有示範操作時另列簡短的操作步驟；第 2 頁起是各個重點，點重點旁的 ▶ 時間 可直接跳到影片那一段。用 ← → 換頁、Esc 關閉，也可匯出成單一 HTML 檔分享。

      整理模式勾選多部影片後按 重點摘要所選 可在背景批次產生；沒有字幕的影片會先語音辨識。摘要頁會顯示 AI 建議的 hashtag，但不會改動影片本身的 hashtag。需要先在 .env 設定 AI。
