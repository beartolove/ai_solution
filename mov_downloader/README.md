# 影片下載器

在本機執行的網頁版影片下載工具。貼上 YouTube、Facebook、Instagram、B站等社群網址，就會依序排程下載成 **MP4**，同時取得 **SRT 字幕**，並內建播放器可直接觀看。

- 下載核心：[yt-dlp](https://github.com/yt-dlp/yt-dlp)（支援上千個網站）
- 帳號授權：使用你 Chrome 裡已登入的 Cookie（透過隨附的 Chrome 擴充功能同步）
- 程式只在你的電腦上執行（`127.0.0.1:8765`），不會上傳任何資料

---

## 功能一覽

| 功能 | 說明 |
|---|---|
| 批次排程下載 | 一次貼上多個網址（每行一個或混在文字中都可），依序下載；可暫停、取消、重試、調整順序 |
| YouTube 播放清單 | 貼上播放清單或頻道網址，自動拆成一部一部依序下載，並加上清單名稱 hashtag |
| 訂閱清單 | 固定追蹤多個 YouTube 播放清單／頻道，一鍵掃描、只下載新影片 |
| 即時進度 | 顯示下載階段（下載影片／音訊、合併、字幕處理）、百分比、速度、剩餘時間 |
| MP4 輸出 | 自動挑選最佳畫質並合併成 MP4，優先 H.264 以確保相容性；可設定最高畫質 |
| 檔名 | 使用影片原標題（自動去除 Windows 不允許的字元），可選擇附加影片 ID；預設只用 Big5 字元（簡體轉正體、去掉表情符號），舊式看圖／預覽軟體也開得了 |
| SRT 字幕 | 優先取正體中文 → 粵語／香港 → 簡體 → 英文 → 原語言自動字幕 |
| 粵語轉台灣用語 | 香港話字幕自動轉為正體中文、台灣用語（例：「佢哋而家喺度」→「他們現在在這裡」） |
| 簡體轉繁 | 簡體字幕以 OpenCC `s2tw` 只轉字形（不會把正確的詞換掉），再以小詞表換成台灣慣用詞（視頻→影片、軟件→軟體、網絡→網路） |
| 重點摘要 | AI 依原始字幕產生最多 5 頁的簡報式重點摘要（燈箱呈現、可跳到影片該段、可匯出 HTML），可單一或批次產生 |
| 語音辨識字幕 | 影片沒有字幕時，自動用 Breeze-ASR-25 在本機辨識出 SRT（MP4 → MP3 → SRT） |
| 外語字幕自動翻譯 | 依字幕**內容**偵測語言，凡非中文（英文、日文、阿拉伯文…）都可自動翻成正體中文；可選只保留原文／翻譯／另存雙語；翻譯引擎可選 Google、雲端 AI、Codex 或**本機 TranslateGemma** |
| 影片資訊 | 自動記錄**來源網址**、原文標題、**原文簡介**、上傳者、上傳日期、標籤；可一鍵複製、可寫備註，影片庫可搜尋上述所有內容 |
| Hashtag 分類 | 整理模式可多選／全選影片批次加上或移除 hashtag，影片庫用 hashtag 下拉選單篩選 |
| 星號與排序 | 下載佇列或影片庫都能標星號；可只看星號、星號置頂，並依上傳日期、下載時間、片長、名稱排序 |
| 已看完標示 | 可手動或播放到結尾時自動標示「已看完」，影片庫可篩選尚未看完的影片 |
| 隱藏影片 | 加上 #隱藏 的影片需輸入密碼才看得到 |
| 更改名稱 | 在播放器按標題旁的筆形圖示即可改名，字幕與資訊檔會一併更名 |
| 播放器 | 字幕顯示在控制列上方不被遮住、字幕開關與切換、字幕大小、播放速度 0.5×～3×、全螢幕、子母畫面、鍵盤快捷鍵 |
| 錯誤紀錄 | 所有功能的錯誤與警告集中在 `data\error.log`，並標示類別；左側選單「錯誤紀錄」可篩選、搜尋、展開詳細內容 |
| 介面 | 左側可收合選單、RWD（手機可用）、字型放大縮小、深淺色主題 |

## 系統需求

- Windows 10／11
- [Python 3.10 以上，建議 3.11](https://www.python.org/downloads/)（安裝時請勾選 **Add python.exe to PATH**）
  - `start.bat` 會依序找 3.11、3.12、3.13、3.10；3.9 以下只裝得到舊版 OpenVINO，語音辨識載入模型會當掉，所以不使用
  - 原本用舊版 Python 建的 `.venv` 會改名為 `.venv-old` 保留（不刪除），確認新版正常後可自行刪除
- ffmpeg（第一次執行 `start.bat` 會自動下載到 `tools\` 資料夾）
- Google Chrome（用於同步登入 Cookie）

## 安裝與啟動

1. 雙擊 **`start.bat`**
   - 第一次執行會自動建立虛擬環境、安裝套件、下載 ffmpeg（約 2～3 分鐘）
2. 瀏覽器會自動開啟 <http://127.0.0.1:8765>
3. 要結束程式，關閉黑色命令視窗即可

> 若網站改版導致下載失敗，請執行 **`update.bat`**，或在「設定 → 系統」按「更新 yt-dlp 下載核心」後重新啟動。

## 安裝 Chrome 擴充功能（登入授權用）

新版 Chrome（127 版以後）在 Windows 上使用「應用程式綁定加密」，外部程式已無法直接讀取 Chrome 的 Cookie。因此本專案附了一個小型擴充功能，由 Chrome 自己把登入 Cookie 交給下載器。

1. Chrome 網址列輸入 `chrome://extensions`
2. 開啟右上角「**開發人員模式**」
3. 按「**載入未封裝項目**」，選擇本專案的 **`chrome_extension`** 資料夾
4. 在 Chrome 登入 YouTube、Facebook、Instagram、B站等網站
5. 點擴充功能圖示 →「**同步 Cookie**」

之後擴充功能會在 Chrome 啟動時及每 30 分鐘自動同步。擴充功能另有兩個便利功能：

- 彈出視窗的「**把目前網頁加入下載佇列**」
- 在網頁或連結上按右鍵 →「**用影片下載器下載此頁影片／此連結**」

同步的網站：youtube.com、google.com、facebook.com、instagram.com、bilibili.com、x.com／twitter.com、tiktok.com、threads.net、vimeo.com。要增減網站，請修改 `chrome_extension/background.js` 的 `DOMAINS` 與 `manifest.json` 的 `host_permissions`，再到 `chrome://extensions` 按重新載入。

> Cookie 會存在 `data\cookies.txt`，等同你的登入憑證，**請勿分享給他人**。

**擴充功能配對（v1.24.0）**：第一次按「同步 Cookie」時，下載器會記住這個擴充功能，之後只接受它送來的資料，電腦上其他擴充功能無法送 Cookie、加入下載或操作影片庫。若重新安裝擴充功能、或從別的資料夾載入（擴充功能 ID 會改變），同步會顯示「配對的不是同一個」：到「設定 → 帳號授權」按「**解除配對**」，再回擴充功能按「同步 Cookie」即可。

### 會員影片：從無痕視窗同步 YouTube 登入

YouTube 會定期「輪替」一般分頁裡的登入 Cookie，程式拿到的那份可能很快就失效，結果 Chrome 能播、下載器卻被判定沒有會員資格。這時改用無痕視窗同步（只需做一次）：

1. `chrome://extensions` →「影片下載器同步」→「詳細資料」→ 開啟「**允許在無痕模式下執行**」（第一次才需要）
2. 開一個無痕視窗（Ctrl+Shift+N），到 youtube.com 登入**有會員資格的帳號**
3. 點擴充功能圖示 →「**從無痕視窗同步 YouTube 登入**」
4. **直接關閉無痕視窗，不要按登出**（登出會讓這份 Cookie 作廢）

之後下載 YouTube 時會優先使用這份登入（存在 `data\cookies_youtube.txt`），其他網站照常使用一般同步的 Cookie。設定頁「帳號授權」會顯示目前 YouTube 的登入來源，也可以按「改回使用一般分頁的 YouTube 登入」。若之後又失效（例如在別處登出所有裝置），重做一次即可。

### 其他 Cookie 來源（設定 → 帳號授權）

| 模式 | 適用情境 |
|---|---|
| Chrome 擴充功能同步（預設） | 建議使用。若尚未同步，會自動改用「直接讀取瀏覽器」 |
| 直接讀取瀏覽器 Cookie | Firefox 可正常使用；Chrome／Edge 新版在 Windows 上多半會失敗 |
| 指定 cookies.txt 檔案 | 使用其他工具（如 Get cookies.txt LOCALLY）匯出的 Netscape 格式 cookies.txt，在「cookies.txt 路徑」填完整路徑；請放在 `data` 以外，`data\cookies.txt` 是擴充功能同步專用、會被覆蓋 |
| 不使用 Cookie | 僅下載公開影片 |

若 Cookie 讀取失敗，程式會自動改用「未登入模式」重試，並在工作卡片上顯示提醒。

## 使用方式

### 下載

1. 左側選單「**下載佇列**」
2. 貼上網址（可多個），按「**加入佇列**」（或 `Ctrl + Enter`）
3. 卡片會顯示進度；完成後按 ▶ 可直接播放

檔案存放於專案的 **`download`** 資料夾（可在設定中修改），例如：

```
download\
  影片標題.mp4
  影片標題.zh-TW.srt      ← 正體中文（台灣用語）
  影片標題.en.srt         ← 外語原文（檔名為語言代碼，如 en、ar、ja）
  影片標題.zh-TW-en.srt   ← 中文＋原文雙語（選擇「雙語」時）
  影片標題.meta.json      ← 影片資訊：來源網址、原文標題、原文簡介、上傳者、備註
```

### 下載 YouTube 播放清單

- 貼上**播放清單網址**（`https://www.youtube.com/playlist?list=…`）或**頻道影片頁**，會自動拆成一部一部加入佇列依序下載，每部都有自己的進度、字幕、翻譯與資訊檔
- 貼上的是**影片網址但帶有 `&list=…`**（從清單中點進去的影片）時，依下載頁的勾選「含播放清單的影片網址，下載整個清單」決定只下載該影片或整個清單
- 清單中的影片會自動加上清單名稱的 hashtag（可在設定關閉），之後可在影片庫用 hashtag 下拉選單整批找出來
- 佇列裡的清單卡片可「取消此清單中尚未開始的影片」；私人清單請先同步 Cookie
- 單一清單預設最多 500 部，可在「設定 → 下載」調整

### 訂閱清單（固定追蹤的播放清單）

1. 左側選單「**訂閱清單**」，貼上常看的播放清單或頻道網址（可一次貼多個）
2. 選擇加入方式：
   - **只追蹤之後的新影片**：現有影片不下載，只記下來，之後有新的才抓
   - **現有影片全部下載**：先把清單裡的都抓下來，之後也持續追蹤
3. 之後只要按「**一鍵掃描全部新影片**」，程式會逐一檢查每個清單，把新影片加入下載佇列（掃描會排在佇列最前面）
4. 每個訂閱可勾選「**自動星號**」，新影片下載後自動加星號；按「看影片」可在影片庫篩出該清單的影片
5. 已經下載過、或之前掃描時看過的影片不會重複下載；就算看完把影片刪了，也不會再被抓回來
6. 在下載佇列的播放清單卡片上，也可以直接按「加入訂閱清單」
7. **補齊缺少的影片**：訂閱卡片會顯示「清單共 N 部，影片庫已有 M 部」。若有缺少，按該訂閱的「補齊缺少的」（或上方「補齊全部缺少的影片」），清單裡「從沒下載過」的影片會全部下載（你刪除過的不算）。勾選「一律補齊」則每次掃描都自動補齊

8. **刪除過的影片不會再抓回來**：程式會記得每部下載過的影片（`data\\history.json`）。你刪掉的影片視為已看完，不論一般掃描或補齊都不會再下載；想重看時，把該影片的網址直接貼到下載佇列即可

**為什麼清單有 6 部、影片庫只有 3 部？** 常見原因：加入訂閱時選了「只追蹤之後的新影片」（現有的不下載）；影片看完後被刪除（卡片會顯示「N 部看過已刪除」，不會再抓）；下載失敗（私人、會員限定、地區限制）；或影片被設為隱藏。從沒下載過的影片，按「補齊缺少的」即可抓回來。

> 掃描需要下載佇列處於「執行中」；如果佇列被暫停，請先按「繼續佇列」。私人清單需先同步 Cookie。

### 播放

左側選單「**影片庫**」→ 點選影片。

| 按鍵 | 功能 |
|---|---|
| 空白鍵／K | 播放／暫停 |
| ← → | 倒退／快轉 5 秒 |
| ↑ ↓ | 音量 |
| < > | 減速／加速 |
| C | 字幕開關 |
| F | 全螢幕（或雙擊畫面） |
| M | 靜音 |
| W | 標示／取消「已看完」 |
| S | 標示／取消星號 |

播放速度、字幕開關、字幕大小、音量會記住，下次開啟沿用。

### 影片資訊、改名與搜尋

播放器下方的資訊區塊：

- **來源網址**：下載時自動記錄當初貼上的網址，可「複製網址」或「修改」；舊影片沒有紀錄時可手動補登
- **原文簡介**：自動保存原網站的影片說明文字，可「複製簡介」（連同原文標題與網址），或按「重新抓取」從來源網址更新（舊影片補抓也用這個）
- **我的備註**：自由記下重點或關鍵字
- **改名**：按標題旁的筆形圖示，輸入新名稱後儲存；影片、字幕、資訊檔會一起更名

### Hashtag 與整理模式

- **排除 hashtag（可複選）**：影片庫的「−# 排除 hashtag」輸入框，輸入要排除的 hashtag（有建議清單，可用逗號或空白一次輸入多個）後按「排除」，帶有這些 hashtag 的影片就不顯示；已排除的列在下方，按 ✕ 取消或「全部取消」。搜尋框也可輸入 `-#標籤` 排除、`-詞` 排除標題或簡介含有該詞的影片

1. 影片庫按「**整理模式**」，點影片卡片即可勾選；可先用搜尋或 hashtag 篩選，再按「**全選**」
2. 在上方輸入 hashtag（可用逗號或空白一次輸入多個，`#` 可省略），按「**加到所選影片**」
3. 要移除時，從「移除 hashtag…」下拉選單選擇；也可在這裡批次刪除影片
4. 之後用搜尋框旁的「**全部 hashtag**」下拉選單篩選，或直接點卡片上的 hashtag
5. 單部影片也可在播放器下方的「Hashtag」區塊新增或移除

### 星號與排序（快速找到想先看的影片）

- **標星號**：下載佇列每張卡片標題前的 ☆（貼上網址後就能先標，下載完成會自動帶到影片庫）、影片庫縮圖右下角的 ☆、播放器的「☆ 星號」按鈕（`S` 鍵），或整理模式批次標示
- 對**播放清單**那張卡片標星號，清單內所有影片都會加上星號
- **只看星號**：影片庫按「★ 只看星號」；再把觀看狀態選「尚未看完」，就是「想先看、還沒看」的清單
- **星號置頂**：勾選後，不論用哪種排序，有星號的影片都排在最前面
- **排序**：最近下載、最早下載、上傳日期（新→舊／舊→新）、片長、名稱、檔案大小；沒有上傳日期的舊影片會排在最後（可按播放器的「重新抓取」補上）

### 標示已看完

- 播放器標題列按「**標為已看完**」（或按 `W` 鍵），再按一次可改回未看
- 影片播放到結尾會自動標示為已看完（可在「設定 → 下載」關閉）
- 影片庫的卡片會顯示「✓ 已看完」；用搜尋框旁的下拉選單可切換「全部影片／尚未看完／已看完」
- 整理模式中可多選後批次「標為已看完」或「標為未看」

### 隱藏影片（密碼）

1. 先到「**設定 → 隱藏影片**」設定密碼（至少 4 個字元）
2. 在整理模式選好影片，按「**🔒 設為隱藏**」（等同加上 `#隱藏`）
3. 隱藏的影片不會出現在影片庫與下載佇列；要看時按影片庫的「**隱藏影片**」輸入密碼，看完按「**重新上鎖**」
4. 解鎖 2 小時未使用、或重新啟動程式，會自動上鎖

> 這是介面層級的隱藏：影片檔仍存放在下載資料夾，用檔案總管依然看得到。忘記密碼時，刪除 `data\lock.json` 即可重新設定。

影片庫的搜尋框會同時比對：檔名、原文標題、簡介、上傳者、標籤、#hashtag、備註、來源網址；可用空白分隔多個關鍵字。

> 資訊存在影片旁的 `.meta.json`，搬移影片時請一起帶走。若在檔案總管自行改名，請連同字幕與 `.meta.json` 一起改。

### 字幕處理規則

1. **挑選字幕來源**（每部影片挑一條最適合的）：
   人工字幕：正體中文 → 粵語／香港 → 簡體中文 → 影片原語言 → 英文
   沒有人工字幕時：取影片「原始音軌語言」的自動字幕（不取 YouTube 機器翻譯版本，也會避開 AI 配音音軌產生的字幕）
2. **轉換**：
   - 粵語：口語詞轉書面語（嘅→的、咗→了、喺→在、佢哋→他們、點解→為什麼…），再轉台灣正體與用語
   - 簡體／香港繁體：OpenCC 轉台灣正體與台灣慣用詞
   - 其他語言：以字幕「內容」判斷是否為中文（不只看標籤），非中文一律依設定保留、翻譯或輸出雙語
3. 翻譯引擎可在「設定 → 字幕 → 翻譯引擎」選擇：
   - **Google 翻譯**（預設）：免費、不需金鑰，4 批同時翻譯
   - **AI 翻譯**：品質較好（會參考影片標題與簡介、前後文，用詞更符合台灣習慣），需要自備 API，見下方「AI 翻譯設定」
4. YouTube 自動字幕原本是「滾動式」（每格兩行、時間重疊），程式會自動整理成一次一行，播放時不再上下跳動
5. 若翻譯失敗（例如網路問題），會保留原文字幕並在卡片上提示；之後可在播放器按「翻譯成中文字幕」或「重新翻譯中文字幕」
6. 若中文字幕中還有沒翻到的句子，影片庫卡片會顯示「N 句未翻」，播放器按鈕會變成「補翻未翻譯的 N 句」，只翻缺的部分；翻譯異常會記錄在 `data\error.log`（類別「翻譯」）
7. 在播放器翻譯時，下方會出現進度卡，顯示目前批次、百分比與預估剩餘時間，翻譯期間可以繼續看影片；完成後會自動換上中文字幕

### 重點摘要（AI 簡報）

用 AI 依影片的**原始字幕**整理成最多 5 頁的簡報式重點摘要，以燈箱方式呈現（字級 18 以上，跟著介面的字型縮放）：

| 頁 | 內容 |
|---|---|
| 第 1 頁 | 這個影片主要講什麼、影片長度／上架日期／頻道／網站、hashtag、100 字內的大綱、✔／✕ 是否「講概念、有範例、有程式」；有示範操作時另列「步驟描述」（3～6 個簡短步驟） |
| 第 2～5 頁 | 各個重點（標題＋2～4 條要點），附「▶ 時間」可直接跳到影片那一段 |

- **單一影片**：播放器按「📝 重點摘要」；已經有摘要時直接開啟，燈箱上可「重新產生」
- **多部影片**：影片庫按「整理」勾選影片 →「📝 重點摘要所選」，在背景一部一部產生（已有摘要的可選擇略過）
- 已有字幕的影片直接使用現有字幕（包括下載時自動語音辨識產生的字幕），不會重新辨識；完全沒有字幕的影片才會**先語音辨識**再摘要
- 摘要第 1 頁的 hashtag 只顯示在摘要頁面，**不會改動影片本身的 hashtag**（舊版曾自動加到影片上，可到「設定 → AI 翻譯」按「移除重點摘要先前自動加到影片的 hashtag」清除）
- 有摘要的影片卡片會顯示「📝 已摘要」，點一下即可開啟；影片庫的「摘要」下拉選單可篩選已摘要／未摘要的影片（搭配整理模式「全選」→「重點摘要所選」，就能一次補做所有未摘要的影片）
- 燈箱上「匯出 HTML」可存成單一網頁檔（離線可看、可分享；YouTube 影片的時間連結會開到該段）
- 操作：← → 或滑動換頁、Esc 關閉；摘要存成影片旁的 `標題.summary.json`，改名、刪除影片時會一起處理
- 被 Azure 內容篩選擋下（多半是誤判，例如教學影片裡唸出的提示詞）時，會自動拿掉簡介重試，再不行就分段整理、略過被擋的小段，盡量仍產生摘要（最後彙整若仍被擋，會直接用各段筆記組成摘要，不會整份失敗；已整理好的段落會暫存，重試時不必重做）；若是 Azure 封鎖清單的詞（例如 Claude）造成，程式會自動找出並加入「遮蔽詞」（送出前換成代號、回來再換回），之後翻譯與摘要都不再被擋；燈箱下方會標出被擋的時間點（點了可跳到影片該段），錯誤紀錄也有被擋的原文
- 字幕翻譯也可在「翻譯引擎」選「本機 Codex CLI」，與摘要共用同一組 Codex 設定（Codex 漏翻的少數句子仍會用 Google 補翻）
- 訂閱清單的卡片可勾選「不做摘要」：該清單的影片在批次摘要時會自動略過，單獨產生時會先詢問
- **摘要使用的 AI**（設定 → 重點摘要）：
  - `.env` 設定的 AI（Azure／OpenAI 相容）：預設
  - 本機 Codex CLI：先安裝 `npm install -g @openai/codex` 並執行 `codex login`，選這個選項後按「測試 Codex 連線」確認，再按「儲存設定」。Codex 用你自己登入的帳號、不經過 Azure，不會被內容篩選擋下；每次呼叫約數秒到數十秒
- 失敗原因會寫在錯誤紀錄的「重點摘要」類

### 本機原有的影片

把自己原有的影片放進下載資料夾裡的 `local_movies` 子資料夾（例如 `D:\mov_dowoloader：download\local_movies`），就會出現在影片庫，卡片標示「📁 local_movies」，並自動加上「#本地影片」hashtag（可用 hashtag 篩選；手動移除後不會再加回），功能與下載的影片相同（播放、語音辨識、翻譯、重點摘要、圖片摘要、改名、hashtag、刪除）。字幕、摘要等檔案會產生在影片旁邊。

要納入其他子資料夾，到「設定 → 下載 → 影片庫也納入的子資料夾」填寫，多個用逗號分隔（只限下載資料夾裡的子資料夾）。

### 圖片摘要（自備的圖片）

若影片旁有檔名為「影片標題＋頁碼」的圖片（例如 `影片標題01.png`、`影片標題02.png`…，頁碼 1～2 位數，支援 png／jpg／webp），程式會自動視為這部影片的圖片摘要：

- 影片庫卡片出現「🖼 圖片摘要 N」，播放器出現「🖼 圖片摘要（N）」按鈕，按下以燈箱逐頁觀看
- ← → 鍵、點圖片左右側、兩側的 ‹ › 按鈕或手機左右滑動換頁；圖片會盡量放大到整個視窗；「開啟原圖」在新分頁看原尺寸
- 影片改名、刪除時，圖片會一起處理
- 影片庫的「摘要」下拉選單可篩選「🖼 有圖片摘要」「沒有圖片摘要」「有任一種摘要」

### 語音辨識（影片沒有字幕時）

沒有任何字幕可下載的影片，程式會自己「聽」出字幕：

1. 用 ffmpeg 把 MP4 抽出聲音，存成 MP3
2. 用 **Breeze-ASR-25** 模型（OpenVINO 格式）把聲音辨識成 SRT
3. 照字幕設定處理：中文轉成台灣用語；外語依設定保留或翻譯成正體中文

- **自動**：下載時發現影片沒有字幕就自動辨識（「設定 → 語音辨識」可關閉）
- **手動**：在影片庫打開沒有字幕的影片，按「語音辨識產生字幕」，下方會顯示進度，可取消
- **批次**：影片庫上方會顯示「N 部影片沒有字幕：批次語音辨識」，按下後在背景一部一部處理，進度卡會顯示完成數、目前影片、預估剩餘時間，可隨時停止；期間可照常下載與播放。只想處理部分影片時，用整理模式勾選後按「語音辨識所選」
- 用下拉選單的「沒有字幕」可以篩出還沒有字幕的影片；沒有聲音或沒人說話的影片會標示「無語音」，批次時自動跳過
- **辨識模型（v1.25.0）**：「自動」時中文、中英夾雜或判斷不出來的影片用 **Breeze-ASR-25**；確定是外語（依下載時記下的原始語言，舊影片看標題與簡介）改用 **Whisper large-v3-turbo**，外語較準也較快。可在設定改成一律用其中一個；沒有 turbo 模型時照舊用 Breeze
- **模型位置**：Breeze 資料夾留空時，讀取「本機 AI 模型」模型位置下的 `asr\ov\breeze-asr-25`，沒有才用 `C:\Users\<使用者>\AppData\Roaming\KeyboardFree\models\ov\breeze-asr-25`；也可直接填其他資料夾（需含 `openvino_encoder_model.xml` 等檔案）
- **第一次使用**會自動安裝 `openvino-genai`（2026.4 以上）並載入模型，需要幾分鐘；之後同一次執行期間模型會留在記憶體
- **版本相容**：模型若是用比這台電腦更新的 OpenVINO 轉出，直接載入會讓程式當掉，所以載入前會先比對；不相容時會顯示原因（通常執行 `update.bat` 即可，Python 3.9 以下需改裝 Python 3.11）
- **速度**取決於電腦：執行裝置選「自動」會先試顯示卡，不行再用處理器
- Breeze-ASR-25 專長是台灣華語與中英夾雜；純英文、日文等其他語言的影片準確度可能較差
- 勾選「保留 MP3」會把抽出的聲音檔留在影片旁邊

### 本機 AI 模型（D:\models，v1.25.0）

語音辨識、本機翻譯、本機重點摘要的模型都放在同一個「模型位置」，和「影音轉逐字稿」（transcribe）專案共用同一份，不用重複下載。

- **模型位置**：依序取「設定 → 本機 AI 模型 → 模型位置」→ 環境變數 `MODELS_ROOT` → `D:\models`
- **Gemma 4 可在設定頁直接下載**（v1.26.0）：表格裡還沒有的 Gemma 4 旁邊按「下載」，會標出這台電腦建議的大小。Hugging Face 公開模型、不需帳號；在背景下載並顯示進度，可照常使用；中斷後再按一次會續傳
- Breeze、turbo（需轉換格式）與 TranslateGemma（需管理者同意條款）無法從這裡下載：向管理者索取對應資料夾（transcribe 的母機已有），複製到模型位置即可，不用重新啟動
- 本程式**不會刪除任何模型**
- 設定頁「本機 AI 模型」會列出每個模型是否就緒、用途與位置

| 模型 | 資料夾（模型位置底下） | 用途 |
|---|---|---|
| Breeze-ASR-25 | `asr\ov\breeze-asr-25` | 語音辨識：中文、中英夾雜（主力） |
| Whisper large-v3-turbo | `asr\ov\large-v3-turbo` | 語音辨識：英文、日文等外語影片 |
| TranslateGemma 4B | `llm\translategemma-4b-it` | 翻譯引擎「本機 TranslateGemma」 |
| Gemma 4 E2B／E4B／26B-A4B | `llm\gemma-4-E2B-it-int4-ov` 等 | 重點摘要「本機 Gemma 4」；依記憶體自動挑大小（16 GB 以下 E2B、16～63 GB E4B、64 GB 以上 26B），也可指定 |

- **本機翻譯**：「翻譯引擎」選「本機 TranslateGemma」，外語字幕就在這台電腦翻成中文，不上傳、不需要金鑰，也不會被 Azure 內容篩選擋下
- **本機摘要**：「摘要使用的 AI」選「本機 Gemma 4」。長影片可能要數分鐘到十幾分鐘，品質通常不如雲端 AI，適合沒有網路或不想上傳時使用
- 執行裝置「自動」時，有 Intel 顯示卡先用，不行改用處理器；同一時間只留一個本機模型在記憶體，閒置 10 分鐘自動釋放
- 本機模型與語音辨識共用 openvino-genai（2026.4 以上），第一次使用時自動安裝；載入前會比對版本，避免新版模型讓程式當掉

### AI 翻譯設定（選用）

1. 把專案中的 `.env.example` 複製一份，改名為 `.env`
2. 填入 `LLM_ENDPOINT`（API 端點）、`LLM_API_KEY`（金鑰）、`LLM_MODEL`（部署或模型名稱）
3. 依服務選擇 `LLM_API_STYLE`：Azure OpenAI／APIM 閘道用 `azure`，OpenAI 相容服務用 `openai`；金鑰標頭 `LLM_KEY_HEADER` 依閘道要求填 `api-key` 或 `Ocp-Apim-Subscription-Key`
4. 到設定頁按「**AI 連線診斷**」，會逐步檢查：.env 設定 → DNS → HTTPS 連線 → 金鑰與模型 → 實際翻譯；全部通過後，「翻譯引擎」選 AI 翻譯並儲存（修改 .env 後不需重新啟動，再按一次診斷即可）
5. AI 回傳格式不正確的段落會自動改用 Google 補翻
6. 常見錯誤：「找不到主機」→ `LLM_ENDPOINT` 填錯或需連公司 VPN；「HTTP 401／403」→ 金鑰或 `LLM_KEY_HEADER` 錯；「ModelNotAllowed」→ `LLM_MODEL` 要改成閘道允許的模型名稱（診斷會直接告訴你）；「HTTP 404」→ 部署名稱或 `LLM_API_STYLE` 錯；「content_filter」→ Azure 內容篩選誤判，被擋的句子會自動改用 Google 翻譯，常發生可在 Foundry 為該部署設定較寬鬆的內容篩選；「API version not supported」→ 改用 v1 端點（`LLM_ENDPOINT=https://<主機>/openai/v1`、`LLM_API_STYLE=openai`）
7. Azure AI Foundry：`LLM_ENDPOINT` 可直接貼專案端點（`…services.ai.azure.com/api/projects/<專案>`），程式會自動改用同主機的 `/openai/v1`；`LLM_MODEL` 填部署名稱
8. 遮蔽詞：Azure 部署若設了封鎖清單（例如擋下 `Claude`），可在 `.env` 加 `LLM_MASK_WORDS=Claude`；程式遇到被擋時也會自動找出並記住（`data\llm_mask.json`），設定頁可查看與清除

> `.env` 內含金鑰，已列入 `.gitignore`，請勿分享。使用公司或組織的 API 前，請先確認內部使用規範與費用。

> 粵語口語轉換為詞庫比對，能處理常見口語，但無法做到人工翻譯的精準度。

## 錯誤紀錄

所有功能的錯誤與警告一律寫進 `data\error.log`，每筆格式為：

```
2026-10-09 11:20:00 [錯誤][翻譯] 翻譯失敗（引擎 llm）：影片標題
  Traceback ...（詳細錯誤追蹤，縮排兩格）
```

- **層級**：「錯誤」＝該動作失敗；「警告」＝已自動處理但值得留意（例如 AI 漏翻幾句已補翻、Cookie 讀取失敗改用未登入模式）
- **類別**：下載、訂閱掃描、Cookie、翻譯、AI 連線、語音辨識、影片資訊、系統、伺服器
- 左側選單「錯誤紀錄」可依類別／層級篩選、搜尋，點一下展開詳細內容；有新的錯誤時選單會出現紅色數字
- 檔案超過 5 MB 會自動改名為 `error.log.1` 重新開始；舊版的 `translate.log` 會在啟動時自動併入
- 需要回報問題時，把相關的幾筆紀錄（或整個 error.log）提供即可；紀錄不含金鑰與 Cookie

## 常見問題

**Q：出現「需要登入」或 403？**
確認已在 Chrome 登入該網站，按擴充功能「同步 Cookie」後，在卡片上按「重新下載」。仍失敗時執行 `update.bat` 更新 yt-dlp。

**Q：Instagram／Facebook 檔名不是貼文標題？**
這些網站的影片通常沒有正式標題，yt-dlp 會以「Video by 帳號」之類的名稱命名。

**Q：B站影片沒有字幕？**
B站的 AI 字幕需要登入才能取得，請確認已同步 bilibili.com 的 Cookie。

**Q：更新後版本號沒變、功能也還是舊的？**
代表舊版程式還在背景執行。請關閉所有黑色命令視窗，再重新執行 `start.bat`（v1.2.1 起會自動關閉舊程式）。版本號若顯示紅色，表示介面與伺服器版本不一致。

**Q：字幕變成阿拉伯文等其他語言？**
有些 YouTube 影片開啟了 AI 多語配音，會出現多條「原始」字幕。v1.1.0 起會依原始音軌挑選，並自動翻成中文。舊檔可在播放器按「翻譯成中文字幕」。

**Q：影片很多時會變慢或播放卡住嗎？**
v1.9.1 起縮圖改用快取的小圖（存在 `data\thumbs`，可隨時刪除，會自動重建），影片庫一次顯示 60 部、捲到底再載入，數百部影片也能正常播放。第一次開啟時縮圖會陸續產生，之後就很快。若個別影片仍無法播放，播放器會顯示原因與編碼；瀏覽器不支援的編碼可按「另存影片」用 VLC 等播放器開啟。

**Q：YouTube 出現「網站拒絕存取（403）」？**
多半是 YouTube 把同步過來的登入 Cookie 輪替掉了（錯誤紀錄會看到「cookies are no longer valid」）。v1.16.3 起程式偵測到這種情況會自動改用未登入模式重抓，公開影片可正常下載；若仍 403，請在設定頁按「更新 yt-dlp」。要下載會員影片，請用擴充功能「從無痕視窗同步 YouTube 登入」，這份登入不會被輪替。

**Q：頻道會員限定的影片可以下載嗎？**
可以，但前提是你的 YouTube 帳號已加入該頻道會員、而且會員等級達到影片要求。請用那個帳號登入 Chrome，確認在 YouTube 網頁上能正常播放該影片，再按擴充功能「同步 Cookie」，回到下載佇列按「重新下載」。沒有加入會員（或等級不夠）則無法下載。若 Chrome 同時登入多個 Google 帳號，請確認 YouTube 右上角目前使用的是有會員資格的那個。若 Chrome 能播、下載器仍失敗，多半是 Cookie 已被 YouTube 輪替失效，請改用「從無痕視窗同步 YouTube 登入」（見上方「安裝 Chrome 擴充功能」一節）；失敗訊息與錯誤紀錄會註明判斷到的原因。

**Q：重複貼上已下載過的影片會怎樣？**
程式會依「網站＋影片 ID」與來源網址判斷（就算你改過檔名也認得出來），直接略過，不重新下載、不重新翻譯。佇列會顯示「已存在」，需要時按「強制重新下載」覆蓋（備註與 hashtag 會保留）。播放清單中已下載過的影片也會自動略過，只下載新的。

**Q：同名影片會覆蓋嗎？**
不會。如果是「不同影片但標題相同」，新下載的檔名會自動加上影片 ID；也可在設定開啟「檔名後面加上影片 ID」讓所有檔名都帶 ID。

**Q：可以從手機使用嗎？**
為了安全，伺服器只接受本機連線（127.0.0.1）。介面本身支援手機尺寸的 RWD 版面。
