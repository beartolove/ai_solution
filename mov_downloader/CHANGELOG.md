## [1.25.0] - 2026-11-02

參考 transcribe 專案，改用 D:\models 下的本機 AI 模型（兩個專案共用同一份，不重複下載）。

### 新增
- **本機 AI 模型位置**（`app\modelpaths.py`）：模型位置依序取「設定 → 本機 AI 模型」→ 環境變數 `MODELS_ROOT` → `D:\models`，每個模型在底下有固定資料夾（與 transcribe 相同）。設定頁新增「本機 AI 模型」區塊，列出各模型是否就緒與位置。本程式只讀取模型，不下載、不刪除
- **翻譯引擎「本機 TranslateGemma」**（`llm\translategemma-4b-it`）：外語字幕在這台電腦翻成中文，不上傳、不需要金鑰，也不會被 Azure 內容篩選擋下；譯文同樣經 `s2tw` 與台灣用語詞表處理
- **重點摘要「本機 Gemma 4」**（`llm\gemma-4-<大小>-it-int4-ov`）：依記憶體自動挑 E2B／E4B／26B-A4B（也可指定）；有 Intel 顯示卡先用，不行改 CPU
  - 新增 `app\local_llm.py`：同一時間只留一個本機模型在記憶體，翻譯與摘要輪流用時自動切換；閒置 10 分鐘自動釋放
- **語音辨識依語言自動挑模型**：中文、中英夾雜或無法判斷 → Breeze-ASR-25；確定是外語 → Whisper large-v3-turbo（`asr\ov\large-v3-turbo`，外語較準、速度較快）。沒有 turbo 模型時照舊用 Breeze
  - 判斷依據：下載時記下的原始語言（新下載的影片資訊多一個 `language`），舊影片看標題與簡介；「影片語言」選了英文、日文、韓文時也改用 turbo
  - 設定「辨識模型」可改成一律 Breeze 或一律 turbo；影片資訊記下用了哪個模型與原因（`asr_model`）
### 變更
- Breeze-ASR-25 模型資料夾空白時，先找模型位置的 `asr\ov\breeze-asr-25`，沒有才用原本的 KeyboardFree 位置
- 設定頁按「儲存」後，語音辨識與模型狀態會立即重新讀取（原本要重新開啟設定頁才更新）
- OpenVINO 編譯快取放在專案的 `.cache\ov`（已列入 `.gitignore`），第二次載入模型較快

## [1.24.0] - 2026-11-02

參考 transcribe 專案（0.14.1）踩過的問題與做法改進。

### 修正
- **簡體字幕轉正體改用 OpenCC `s2tw`（只轉字形）**：原本的 `s2twp` 會連詞彙一起換，把正確的詞也改錯（連接詞→連線詞、對象→物件、發佈→釋出；transcribe 專案 2026-10-31 實測）。大陸用語改由一份只收「幾乎不會換錯」的小詞表處理（視頻→影片、軟件→軟體、網絡→網路、默認→預設、屏幕→螢幕、點贊→按讚…），像「文件、程序、項目、菜單」這類一般詞也常用的不換
- **語音辨識不會再因 OpenVINO 版本太舊而讓整個程式當掉**：模型若用較新版 OpenVINO 轉出，舊版載入時會在底層當掉、攔不到錯誤（transcribe 專案在 Python 3.9 的電腦實測）。新增 `app\ovcompat.py`，載入模型前比對版本，不相容就顯示原因與處理方式
  - 第一次安裝語音辨識元件改為 `openvino-genai>=2026.4`；Python 3.9 以下直接說明需要升級
  - 「設定 → 語音辨識」的模型狀態也會顯示版本不相容
### 變更
- `start.bat` 真的檢查 Python 版本：依序找 3.11（建議）、3.12、3.13、3.10，都沒有就說明要安裝 Python 3.11；舊版 Python 建的 `.venv` 改名為 `.venv-old` 保留（不刪除）後重建。已裝的 openvino-genai 低於 2026.4 時自動更新
- `update.bat`：有用過語音辨識時，一起更新 openvino-genai
- **設定、下載佇列、影片資訊、訂閱清單、字幕、重點摘要等檔案改為「先寫暫存檔、寫完再換上去」**（新增 `app\fsutil.py`），寫到一半關掉程式也不會留下壞掉的檔案
- 版本號改由專案根目錄 **`VERSION`** 檔統一管理（伺服器、介面、擴充功能檢查都讀它）
### 安全
- **Chrome 擴充功能配對**：原本任何 Chrome 擴充功能都能送 Cookie、加入下載，甚至呼叫刪除影片等 API。現在第一次「同步 Cookie」時自動記住該擴充功能，之後只接受它；擴充功能也只能使用同步 Cookie、加入下載、連線檢查三個功能
  - 「設定 → 帳號授權」顯示已配對的擴充功能，可「解除配對」（重新安裝或換資料夾載入擴充功能時使用）
  - 配對資料存在 `data\ext_pair.json`
- 擴充功能更新為 1.2.0：同步失敗時顯示下載器回覆的原因（例如未配對）
### 新增
- `CLAUDE.md`：記錄使用習慣與專案規範，協作前先讀
